# passed — production-frozen стратегии (замороженное ядро)

Конфигурации, прошедшие **полную пререгистрированную батарею**
(даты frozen до прогона, гейты frozen до прогона, kill-правила
обязательны) и промоученные сюда как frozen production-эталоны.
**PASS здесь — regression-контракт, а не приглашение тюнить.**

Правила этой папки:

1. Один модуль на стратегию, **самодостаточный** (никогда не
   импортирует из `experiments/` — доказательная база живёт там,
   это frozen-ядро).
2. Docstring каждого модуля несёт полную provenance-цепочку
   (якоря журнала + хэши коммитов) и frozen-числа вердикта.
   **Любое изменение, сдвигающее эти числа, аннулирует PASS**
   и переоткрывает стратегию как НОВУЮ гипотезу (новый датированный
   пререг в журнале).
3. Сигнальные параметры, универсум, издержки, сплит и гейты frozen.
   Изменения сайзинга/риск-оверлея НЕ входят во freeze passed-модуля,
   но тоже требуют нового пререга (см. историю AVSL: сайзинг менялся
   один раз, через risk-overlay трек).
4. У каждого модуля есть юнит-тесты в `engine/tests/test_passed_*.py`
   (чистые функции) плюс запускаемый self-check, обязанный
   воспроизвести frozen-числа на заархивированных данных.
5. Проверенно-запрещённые изменения записаны в модуле и здесь
   (измерено, не предположено), чтобы никто не перетестировал их
   «на всякий случай».

## Стратегии

### `avsl_cross_s1` — AVSL-cross 4H + S1 vol-target (PASS 5/5, 2026-09-22)

Первая стратегия в истории проекта со статистически значимым
gross-эджем, убитая на фиксированном сайзинге и оживлённая через
пререгистрированный сайзинг-only трек.

| пункт | значение |
|---|---|
| Сигнал | close × AVSL(70,345) cross, 4H, normal arm |
| Стоп / выход | max(\|close−line\|, 2×ATR14) · TP 5R · MTM 500 баров · stop-first |
| Универсум | BTC AVAX BNB DOGE ETH LINK LTC NEAR SOL XRP (Binance 1H→4H) |
| Сайзинг | S1 vol-target: `clip(0.20/rv100, 0.25, 2.0)`, 1% капитала на единицу размера |
| Сегменты | PRIMARY = первые 2/3 · F3 = последние 1/3 (F3 = holdout) |

**Frozen-числа вердикта** (`uv run python -m engine.passed.avsl_cross_s1`
обязан их воспроизвести; доказательство `runs/risk_overlay.log`):

| метрика | PRIMARY | F3 | гейт |
|---|---|---|---|
| Sharpe_NW (accrual, lags 500) | **+1.50** | **+2.84** | ≥ 1.0 оба ✅ |
| Портфельный DD (1%/слот) | **22%** | **12%** | ≤ 25% оба ✅ |
| Net EV на сделку | +0.17R | +0.33R | ≥ 0.10R оба ✅ |
| Активов с EV>0 | 9/10 | 7/10 | ≥ 7/10 оба ✅ |
| Block bootstrap CI (block 500) | excl. 0 | excl. 0 | excl. 0 оба ✅ |

Значимость самого сигнала (confirm-трек, 2026-09-21): NW-z
**+3.31 / +3.85** (lags 500) — эдж реален, это не inflation от
перекрытий.

**Provenance:** screen пререг `bb5098b` → 4H-аномалия на записи →
confirm вердикт `1e0e859` (5/6 PASS, DD 61% FAIL на фиксированном
1%/слот) → risk-overlay пререг `b6005ca` (S1–S4 frozen, risk-first)
→ **выбран S1** `e6b4b4d`.  Полный текст: журнал
(`docs/JOURNAL.md`), разделы «AVSL-CROSS 4H», «RISK-OVERLAY TRACK».

**Измерено-запрещено для наследников** (не перетестировать без
нового пререга; каждое стоило полного рана):

- **Капы конкурентности** (max-open / max-exposure): режут DD до
  21%, но уничтожают PRIMARY-эдж (Sharpe 0.22, EV +0.02R, CI
  покрывает 0).  Кластерные входы НЕСУТ эдж; кап его ампутирует.
- **ATR-перцентильный режимный сайзинг один** (×0.5/×0.25 верхние
  децили): DD остаётся 57%/28% — слишком свободно.

**Декомпозиция (E1–E5, 2026-09-22 — диагност., конфиг не тронут):**
движок = 4H-сетка + wide-TP асимметрия; AVSL cross — усилитель
(+0.037R/+0.167R над matched null), только 4H (1D мёртв); режим =
low-vol + 2025+ (2023–24 на holdout мёртв); S1 = de-lever +
vol-timing (на PRIMARY погранично).  Полный текст: журнал,
«DECOMPOSITION COMPLETE».  Любое изменение, вдохновлённое этой
картой (trailing, 3×ATR, режимные фильтры) = новый датированный
пререг и закрытие этого модуля.

**Известные ограничения / честные пометки:**

- PRIMARY DD сидит в 3пп под капом — PASS, но без запаса.
- EV в R инвариантен к сайзингу; рост капитала при среднем размере
  0.33 — примерно 1/3 от несайзенной версии — это цена риск-гейта,
  и в этом смысл.
- Числа — до live-scale: отдельный live-scale пререг (сайзинг в
  терминах капитала, площадка, слиппедж, мониторинг, kill switch)
  обязателен до реальных денег.  Модуль — frozen research-эталон,
  не исполнительный бот.
