# Каталог экспериментов

Структура: **семья (папка) → эксперимент (папка) → скрипты**.
Каждый эксперимент — папка с `EXPERIMENT.md` (статус, вердикт,
доказательство, история версий) и скриптами, помеченными
`__version__`. Запуск:

```bash
uv run python -m experiments.<семья>.<эксперимент>.<скрипт> [args]
```

**Правило версий:** `v1.0.0` = evidence-версия — код, получивший
зафиксированный вердикт; изменять запрещено. Любая правка = новая
версия скрипта + запись в таблице «История версий» в `EXPERIMENT.md`.
Общие хелперы — `experiments/_repo.py`; диагностика — `experiments/debug/`
(не эксперименты, реестр — в `docs/EXPERIMENTS.md`).

Результаты складываются в `runs/`; каждый вердикт записывается в
журнал **`docs/JOURNAL.md`** (бывший STATUS.md; снапшот текущего

пререгистрацией. Журнал — доказательная база; README треков —
индекс. Отрицательные результаты сохраняются намеренно: закрытый
трек остаётся закрытым по своему пререгу (без перетюнинга; оживление
только через НОВЫЙ пререг).

## Легенда статусов

- SURVIVOR — прошёл пререгистрированные гейты; вердикт включает
  тренд затухания по фолдам, а не только PASS/FAIL
- EXPECTED — пререгистрирован, гейты frozen, модуль НЕ написан
- SPEC ONLY — есть дизайн-спека, НЕ пререгистрирован, кода нет
- INFRA — загрузчик данных / билдер, без гейтов, безопасно перезапускать
- CLOSED — гейт(ы) провалены по пререгу; вердикт финален
- HISTORICAL — запущено до фикса симулятора D.13g; позитивные числа
  НЕвалидны. Хранится для археологии протокола; не цитировать.

## Смена рынка (не начато)

Fallback-универсум при смерти крипто-треков — акции/форекс/сырьё
(funding-подобные carry-аналоги: dividend capture, FX forward basis,
roll yield). Статус: **ничего не начато; валидный FX- и
stocks-трансфер AVSL закрыт FAIL'ом 2026-09-25** — любой новый
рыночный трек требует новой гипотезы «почему этот универсум несёт
эдж» и нового пререга.

## Правила новых экспериментов

1. **Пререгистрируй до прогона**: правила, параметры, гейты,
   окна оценки — в журнал (формат — см. TTF v1 / ProSP v2).
   Параметр, тронутый после первого рана, убивает трек.
2. **Гейты только на PRIMARY**; затухание по фолдам фиксируется —
   это сигнал crowding, не баг. Затухание — часть вердикта.
3. **Сначала пессимистичная симуляция** (SL-first, слиппедж,
   gap-through-stop scratch), gross EV до издержек, композиционная
   санити-проверка до доверия заголовкам (урок D.13g).
4. Отрицательные результаты остаются: модуль хранится, вердикт в
   журнале, строка с меткой CLOSED в README трека.
5. Новый модуль — в существующую папку трека (или новая папка со
   своим README); строка индекса обновляется.
6. Каждая живая/ожидающая строка здесь несёт якорь на журнал;
   без якоря строка не считается сделанной.
