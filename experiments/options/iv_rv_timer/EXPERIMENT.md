# IV-RV timer — read-out предиктора (волна 1)

**Спека frozen до кода и прогона.** Read-out, БЕЗ гейтов и БЕЗ
стратегии. Один прогон -> `runs/iv_rv_timer.log`.

## Вопрос

Несёт ли таймер DVOL-RV30 информацию о **будущем** VRP (а не только
синхронную, как фаза-0)? Экономическая проверка A3-механики с другой
стороны: фильтр по уровню DVOL vs фильтр по спреду.

## Определения (frozen)

- timer(t) = DVOL(t) - RV30(t), дневной грид (как vol_readout).
- Терцили timer по полной выборке (края 1/3, 2/3).
- Forward VRP: fwd(t) = DVOL(t) - RV30(t+30 дней) — сколько из
  сегодняшней IV реально реализовалось за следующие 30 дней.
- Отчёт: по каждому терцилю n / mean / median / доля fwd>0;
  top-терциль по годам; кросс-таблица терциль(timer) x
  квартиль(DVOL) — пересекаются ли два фильтра.

## Интерпретация (до рана, frozen)

Таймер считается валидным кандидатом на фильтр следующего пререга,
если: mean fwd в top-терциле >= +5pt и >= +3pt выше bottom-терциля.
Это НЕ гейт (read-out): негативный результат закрывает таймер-ветку,
но не трогает уже запущенный A3.
