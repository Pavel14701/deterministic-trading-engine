# Ядро измерений: `engine/core.py` и `engine/battery_v2.py`

Это **не эксперименты**, а измерительная инфраструктура: из неё
импортируются метрики/гейты, которыми считаются вердикты. Менять их —
только через тесты эквивалентности (см. ниже).

## engine/core.py — параметрическое ядро AVSL-линии

Единая реализация всей математики AVSL-протокола. Параметры вынесены
наружу; **дефолты = frozen-значения проекта**, то есть вызов без
аргументов побитово воспроизводит исторические прогоны:

| функция | что делает | frozen-дефолт |
|---|---|---|
| `fast_line_p` | AVSL (любые fast/slow); обёртка над `avsl_ind` | 70/345 |
| `resample_bars_p` | ресемпл 15m→старшие ТФ (polar group_by-sum) | 4H=16×15m |
| `s1_sizes_p` | сайзинг S1: `clip(0.20/rv100, 0.25, 2.0)` | rv100 |
| `nw_sharpe_p` | accrual-поток → NW-Sharpe с HAC-ковариацией | lags 500 |
| `block_bootstrap_ci_p` | стационарный block bootstrap CI | block 500, seed 11 |
| `portfolio_dd_p` | портфельная кривая + max-DD | — |
| `battery_v2` (re-export) | замерная батарея гейтов G1'–G5' | см. ниже |

**Правило изменения.** Любая правка ядра должна держать бит-в-бит
эквивалентность с frozen-копиями в `engine/passed/` — тесты в
`engine/tests/core/` (`test_core.py`: эквивалентность значений;
ресемпл — rtol 1e-12, т.к. polar group_by-sum параллелен).
Новые параметры допустимы только с дефолтом = старому поведению.

## engine/battery_v2.py — замерная батарея v2 (frozen)

Гейты, которыми принимаются/отклоняются эксперименты: G1' (fold-PF),
G2' (DD), G3 (recov), G4 (EV), G5' (NW-z), плюс ENB, concurrency,
кросс-секционный bootstrap, ортогонализация EV против фактора и
разбор по ногам. Ей соответствует пререг `PREREG_BATTERY_V2.md`;
известные ограничения (NW lags на sawtooth-кривых, ENB-обесценивание)
— в `docs/BATTERY.md`. Код frozen: не редактируется, правки = новая
версия файла + запись в журнале.

## Где живут результаты

- Frozen-версии, получившие вердикты: `engine/passed/` ( например
  `avsl_cross_s1.py` — S1 risk-overlay, PASS 5/5).
- Тесты: `engine/tests/{core,passed,legacy}/`.
