# Методология измерения (battery v1 → v2)

## Эволюция

- **battery v1** — выведена из эксплуатации: симулятор D.13g имел
  артефакт gap-through-stop; все позитивные результаты той эпохи
  (champion stack, `experiments/panel/`) НЕвалидны.
- **battery v2** (`engine/battery_v2.py`, frozen,
  `PREREG_BATTERY_V2.md`) — текущий стандарт.  В ходе калибровки
  найдены и исправлены два бага: ENB на полном гриде (введена
  поправка), units-баг searchsorted (ms vs day-id).  Оба исправлены
  до вердиктов, на вердикты не влияли.

## Гейты G1'–G5' (на PRIMARY + holdout F3, оба сегмента)

| гейт | метрика | порог |
|---|---|---|
| G1' | Sharpe_NW (lags 500) | ≥ 1.0 |
| G2' | portfolio DD (1%/слот) | ≤ 25% |
| G3' | net EV на сделку | ≥ 0.10R |
| G4' | доля активов с EV>0 | ≥ 7/10 |

Дополнительные read-out (не гейты): ENB, concurrency p50/p95/max,
leg-разборы (long/short), EV_orth vs фактор (SPY/DXY/BTC-30d),
годовые таблицы, ex-top-20 устойчивость.

## Известные ограничения (зафиксированы измерениями)

1. **NW-дегенерация**: фактор sqrt(1+2·Σρ) с lags≥500 взрывается,
   когда сумма автокорреляций → −0.5 (sawtooth accrual-потоков).
   Встречено в portfolio-layer и AVSL-extended.  Правило: raw Sharpe
   в таких случаях governs narrative; новые пререги с NW lags≥500
   обязаны объявлять дегенеративную ветку заранее.
2. **Производительность**: nw_sharpe O(n·lags); на 39k-барном гриде
   с lags 500 — десятки минут на вызов (FX 4H прогон).  Для больших
   гридов считать один раз и кэшировать.
3. **ENB на коротких окнах** — power-limited (2.56 года при block
   500 ≈ 7 независимых блоков на сегмент).
4. **Power гейта G5** объявляется в пререге, но не смягчает порог.

## Протокол книги

1. Прereg (правила/параметры/гейты/окна) frozen до кода; run
   declaration для prereg-silent деталей.
2. One-shot: FAIL закрывает семью (kill-rule); перезапуск упавшего
   рана = тот же ран, фиксируется как restart.
3. PASS → LATENT → (execution-пререг) → passed (frozen).
4. Отрицательные результаты сохраняются навсегда.
